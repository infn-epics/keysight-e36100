# keysight-e36100

EPICS support for Keysight E36100B series DC power supply (E36103B 20 V / 2 A), reached over TCP/IP through
an asyn port driver (`e36100App/src/e36100Driver.cpp`) polling the readbacks every 1 s.

State programs:
- `e36100RampOn.st`: Set the current limit, switch the output on at 0 V, then ramp to the operating voltage (4 steps); start with `$(P):$(R):RampOn:Start`, stop with `$(P):$(R):RampOn:Abort`.
- `e36100SafeOff.st`: Ramp to 0 V, then switch the output off (2 steps); start with `$(P):$(R):SafeOff:Start`, stop with `$(P):$(R):SafeOff:Abort`.

The layout follows ppt-modulator: a `e36100Support` library for any IOC to link, the `e36100` example IOC in
`iocBoot/ioce36100`, and a simulator in `sim/`.

> Generated by the ARGUS IOC engineer (ioc_scaffold_module) from the module's description. The commands come from the description it was given:
> check them against the device's manual before connecting to hardware.

## Build

In the INFN devcontainer (`ghcr.io/infn-epics/infn-epics-ioc-base`), or anywhere with EPICS base, asyn
 and the sequencer
(put local paths in `configure/RELEASE.local`):

```bash
make
```

## Run against the simulator

```bash
python3 sim/e36100_sim.py --port 5025 &
cd iocBoot/ioce36100
../../bin/linux-x86_64/e36100 st-sim.cmd
```

## Records

Macros: `P` (the IOC prefix), `R` (the device), `PORT` (the asyn port).

| PV | Record | What |
|----|--------|------|
| `$(P):$(R):Connected` | bi | the device answers the poll |
| `$(P):$(R):Voltage_RB` | ai | Output voltage [V]: `MEAS:VOLT?` |
| `$(P):$(R):Voltage_SP` | ao | Output voltage [V]: `VOLT %f` |
| `$(P):$(R):VoltageSet_RB` | ai | Programmed voltage [V]: `VOLT?` |
| `$(P):$(R):Current_RB` | ai | Output current / current limit [A]: `MEAS:CURR?` |
| `$(P):$(R):Current_SP` | ao | Output current / current limit [A]: `CURR %f` |
| `$(P):$(R):CurrentSet_RB` | ai | Programmed current limit [A]: `CURR?` |
| `$(P):$(R):OVP_RB` | ai | Over-voltage protection level [V]: `VOLT:PROT?` |
| `$(P):$(R):OVP_SP` | ao | Over-voltage protection level [V]: `VOLT:PROT %f` |
| `$(P):$(R):Output_RB` | bi | Output state: `OUTP?` |
| `$(P):$(R):Output_SP` | bo | Output state: `OUTP %d` |
| `$(P):$(R):Ident_RB` | lsi | Identification: `*IDN?` |
| `$(P):$(R):Error_RB` | lsi | Oldest error in the queue: `SYST:ERR?` |
| `$(P):$(R):RampOn:Start` | bo | RampOn: start |
| `$(P):$(R):RampOn:Abort` | bo | RampOn: abort |
| `$(P):$(R):RampOn:State` | mbbi | RampOn: Idle/Running/Done/Failed/Aborted |
| `$(P):$(R):RampOn:Step` | longin | RampOn: current step |
| `$(P):$(R):RampOn:Message` | stringin | RampOn: what it is doing |
| `$(P):$(R):SafeOff:Start` | bo | SafeOff: start |
| `$(P):$(R):SafeOff:Abort` | bo | SafeOff: abort |
| `$(P):$(R):SafeOff:State` | mbbi | SafeOff: Idle/Running/Done/Failed/Aborted |
| `$(P):$(R):SafeOff:Step` | longin | SafeOff: current step |
| `$(P):$(R):SafeOff:Message` | stringin | SafeOff: what it is doing |
